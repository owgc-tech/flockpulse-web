### Story Summary
Joseph decided (2026-11-21, FP-254 comment 10632) that FlockPulse stops collecting birthdate. New registration requires two boxes: "I confirm I am 18 or older." and "I accept the Terms of Service and the Privacy Policy." Both are stored with the effective dates of the two documents and a timestamp, in their own table, kept after a member is removed. Existing members see a one-time screen asking for the same two things before they can use the web admin (web) or the app (mobile DIP). The birthdate field is removed from the web registration, founder registration, profile page and API, and all existing birthdates are permanently deleted.

### Repo Target
Web (`owgc-tech/flockpulse-web`): database (two migrations), registration, profile, API, admin shell. Mobile follows. **Sequence:** migration 1 (additive) is applied BEFORE the merge; migration 2 (destructive) is applied AFTER the merge is deployed and after Joseph confirms a read-only preview.
